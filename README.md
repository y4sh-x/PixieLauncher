## 🌌 About Pixie Launcher

**Pixie Launcher** is an Android launcher project for Minecraft: Java Edition.

Built with a mobile-first approach, it aims to bring a modern launcher experience to Android users.

## 🚀 Features

| Feature | Description |
|---|---|
| 🎨 Modern Interface | Clean launcher UI |
| 🔐 Account Management | Supported account management |
| 📦 Version Management | Manage Minecraft versions |
| ⚙️ Mod Loaders | Supported mod loader management |
| ☕ Java Runtime | Java runtime management |
| 🎮 Touch Controls | Mobile gameplay controls |
| 📁 File Manager | Manage launcher files |
| 🖥️ Minecraft Java | Launch Minecraft Java Edition |

## 📱 Platform

- Platform: Android
- Game: Minecraft Java Edition
- Interface: Mobile-first
- Gameplay: Landscape orientation
